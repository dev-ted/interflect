# Discussion prompts

One prompt per lesson. Each asks for a piece of the learner’s own work.

## Visual hierarchy & layout

**Hierarchy is a reading order.** Paste a screenshot of a card you re-ranked. What did the blur test still emphasise, and which lever did you refuse to use?

**Spacing on an 8 point scale.** Share two gaps from a real screen: one inside a group and one between groups. Did the between-group gap end up at least twice the inside gap?

**Grids and alignment.** How many distinct left edges did you count before, and how many after? If you nudged an icon, what did the comment say?

## Typography for interfaces

**Choosing a type scale.** Which ratio did you pick, and which existing font size did you delete because it was only a pixel away from another?

**Line length, line height and rhythm.** Measure one paragraph in your product. How many characters per line, and what did you set `max-width` to?

**Weight, colour and contrast in text.** Which text colour failed contrast on its real background, and what did you replace it with?

## Accessible components

**Focus states people can see.** Where did Tab go that you did not expect, and what was the focus ring sitting on?

**Buttons, links and the right element.** Find a control in your UI that looks like one element and behaves like the other. Which element did you keep, and why?

**Labelling forms and errors.** Rewrite one error you have shipped so it tells the person how to fix the field. What did the old message say?

## Design systems & tokens

**From hard-coded values to tokens.** Paste the three closest hex values your audit found. Which single primitive did they become?

**Semantic tokens and theming.** Name one token you almost called by its colour. What role name did you use instead, and what does it point to in dark mode?
