# Companion materials

One-page references a producer can turn into end cards or downloads. The lesson page in the app already holds the full write-up and quiz. These are the extras named in the scripts.

## Visual hierarchy & layout

| Lesson | Material | What it contains |
| --- | --- | --- |
| Hierarchy is a reading order | Checklist | Ranking written first. One or two levers per step. Blur test. |
| Spacing on an 8 point scale | Scale card | 4, 8, 12, 16, 24, 32, 48, 64. Group gap at least twice the inside gap. |
| Spacing on an 8 point scale | Redline checklist | Annotate 8, 16, 24. Flag any number not on the scale. |
| Grids and alignment | Overlay | Full width, 8/4, three equal columns. |
| Grids and alignment | Snippet | Page grid with `minmax(0, 1fr)` and the profile header. |

## Typography for interfaces

| Lesson | Material | What it contains |
| --- | --- | --- |
| Choosing a type scale | Worksheet | Base, ratio, five rounded steps, role names. |
| Line length, line height and rhythm | Measure card | 45–75 characters, 65ch default, unitless line height. |
| Weight, colour and contrast in text | Contrast card | `#171717`, `#404040`, `#737373` on white. AA for normal text is 4.5 to 1. |
