Design systems · Lesson 1

Same card, now it moves with the system

/* before */
.card {
  background: #fff;
  border: 1px solid #e4e4e4;
  border-radius: 7px;
  padding: 15px;
}
/* after */
.card {
  background: var(--neutral-0);
  border: 1px solid var(--neutral-200);
  border-radius: var(--radius-2);
  padding: var(--space-4);
}
Spacing on an 8 point scale

Replace ad hoc margins with a small spacing scale.

  • 7px radius → radius-2 (8)
  • 15px padding → space-4 (16)
  • #e4e4e4 → neutral-200

Not a different design. Drift.
